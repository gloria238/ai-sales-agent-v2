## 处理原则

先共情再解决——永远先说"我理解您的顾虑"，再给方案，不要直接反驳。用数据说话——引用具体数字和案例，不是空泛的"我们产品很好"。转化而非对抗——客户异议往往隐藏着需求，"太贵了"的潜台词可能是"我还没看到足够价值"。不编造——知识库没有的信息说"我确认一下再回复"比说错好。

## 价格异议

**"太贵了，我们预算有限"**
共情："完全理解——确保每一分钱花在对的地方是最重要的。"数据支撑："标准版 ¥9,800/月，3 个 AI 坐席同时处理约 150 个并发会话——远超一个初级客服的产能（约 ¥8,000/月）。加上 7×24 小时在线，客户不需要排队等上班时间。"降级策略："如果预算紧张，先从标准版开始。一个月 ¥9,800 是一个 SDR 月薪的 1/3-1/2，能覆盖 3 倍工作量。等 ROI 验证后再升级专业版——升级即时、数据不丢。"对标："网易七鱼标准版也要 ¥12,000+/月，且 AI 主要是关键词匹配。我们是基于大语言模型的语义理解——两个代际的技术。"详见 competitor-battlecards.md 网易七鱼对比。

**"我们自己用 ChatGPT 不就行了"**
共情："ChatGPT 确实是非常强大的工具。"差异化——ChatGPT 不知道你的产品细节会编造信息；我们的 AI 严格基于知识库，每句话带引用溯源。ChatGPT API 需要技术人员对接，我们开箱即用。ChatGPT 不提供 HITL 审批流——销售场景 AI 绝不能直接发邮件。详见 competitor-battlecards.md ChatGPT vs 启云对比。

## 数据安全异议

**"我们公司的数据不能放在外部服务器上"**
共情："数据安全是每家企业最核心的关切——尤其金融、医疗、政务行业。"解决方案——企业版完全私有化部署，所有数据存储在你的服务器上，AI 引擎可在你机房运行。通过 ISO 27001 和等保三级认证。参考案例——case-studies.md 金融券商案例：3,000+ 合规文档完全留存内网，外部零访问。

**"AI 会不会把我们公司的数据送给大模型训练？"**
明确澄清——不会。我们调用 DeepSeek API 时仅传输当前查询和知识库上下文，不传输完整客户 PII。传输数据仅用于生成当前回答，不用于模型训练。企业版 AI 引擎可在本地运行，数据根本不出企业防火墙。详见 compliance-policy.md。

## 效果疑虑

**"AI 真的能替代人工销售吗？"**
澄清定位——不是替代，是替代重复性工作。AI 负责线索评分、起草初稿、回复常见问题。人类销售负责关系建立、复杂谈判、最终决策。HITL 架构——AI 起草但绝不自动发送。数据支撑——case-studies.md 电商案例：日处理 10 万+会话，AI 自动解决 85%，人工坐席从 200 人降至 30 人处理高价值问题，年节省人力成本 ¥800 万。

**"你们产品太新了，我不放心"**
共情："选择新技术方案需要勇气——我理解。"信任建立——过去 24 个月迭代了 21 个大版本。50+ API 端点、52 个自动化测试、通过安全审计。14 天免费试用不绑卡。试用数据和配置可无缝升级到正式版。

**"我们行业比较特殊，通用方案可能不合适"**
共情："每个行业确实有独特的需求和术语。"应对——知识库自定义——上传你的行业文档后，AI 自动学习专业术语和业务逻辑。评分模型可按行业自定义权重。企业版支持定制开发（SLA/品牌/UI/工作流）。参考案例——case-studies.md 券商和电商两个完全不同的行业，都取得了显著效果。
