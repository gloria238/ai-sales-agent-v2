# 启云科技 QiCloud — 新客户上线指南

> 版本: V3.0 | 更新: 2026-07-07 | 层级: 运营支撑层
> 适用: 标准版/专业版

## 上线流程（3 个工作日）

### Day 1: 账号与基础配置
注册→email 验证→创建组织（自动）。邀请团队成员（Admin/Operator/Viewer）。配置企业信息。第一个注册用户自动成为 Owner。

### Day 2: 知识库搭建
收集核心文档（产品手册/定价表/FAQ/案例/竞品对比）。上传到知识库，系统自动解析+分块+向量化，1h 生效。在 KB Playground 验证 AI 回答质量。问题回答不好→补充更详细文档→重新上传。

**知识库最佳实践**: 按三层组织（核心层/销售参考层/运营层）。每个文档标版本号和更新日期。不要把所有信息塞进一个巨型文档。FAQ 用 Q&A 格式检索得分更高。关键数字（价格/规格/SLA）单独成表。FAQ 和定价表做交叉引用。多语言内容按语言版本分别上传。

### Day 3: 渠道配置与上线
配置邮件（Resend API Key）、聊天（网站 Widget 或 Portal）、微信/企微（专业版，需企业微信管理员授权）。模拟客户发消息测试 AI 草稿质量。正式上线。

## 持续维护
每周: 检查搜索命中率。每月: 补充新客户问题和产品更新文档。每季: 跑 `pnpm eval:sales:retrieval` 确认检索质量。文档更新: 同名重新上传→自动检测→删旧 chunks→重建→清缓存。

## 私有化部署流程（企业版）
需求评估（1-3 天）→环境准备→部署实施（1-4 周）→验收测试→上线。支持 AWS/阿里云/腾讯云/自建机房。详见 technical-specs.md。
