# 启云科技 QiCloud — 常见问题（FAQ）

## 一、产品功能（10 题）

### Q1：QiCloud 的 AI 销售坐席能做什么？
AI 销售坐席可以自动处理客户咨询、给线索打分、根据客户消息生成个性化回复、推荐合适的销售话术，还能自动预约会议。它 7×24 小时在线，客户发消息 30 秒内就能收到回复。

### Q2：支持哪些沟通渠道？
目前支持五个渠道：企业微信、个人微信、电子邮件、网页 Widget（一行代码嵌入官网）、REST API 自定义接入。所有渠道的消息会汇总到统一收件箱。

### Q3：AI 会不会自动发送消息给客户？风险怎么控制？
**不会。** 所有 AI 生成的消息默认进入"待审核"状态（HITL 模式），需要销售人员或经理手动确认后才会发送。这是 QiCloud 的核心安全设计。基础版除外——基础版为降低使用门槛，AI 生成即发送，但可通过升级到专业版开启审核流程。

### Q4：知识库支持哪些文件格式？
支持 PDF、Word（.docx）、Markdown（.md）、纯文本（.txt）和 FAQ 问答对（JSON 格式）。单个文件最大 10MB。上传后系统自动分段、向量化并建立索引，通常 30 秒内完成。

### Q5：知识库的检索准确率怎么样？
采用混合检索技术：向量语义搜索 + 全文关键词搜索并行执行，然后通过 RRF 算法融合排序。在 20 条标准测试集上，Precision@5 达到 78%，Recall@5 达到 85%。如果知识库中没有相关信息，AI 会明确告知而不是编造。

### Q6：支持哪些语言？
AI 销售坐席支持中文、英文、日文、韩文——AI 会自动检测客户消息的语言并用相同语言回复。管理后台目前仅支持中文。客户 Portal 支持中文和英文自动切换。

### Q7：可以对接我们现有的 CRM 系统吗？
可以。专业版和企业版提供 RESTful API，你可以通过 API 将 QiCloud 集成到现有的 CRM、OA 或 ERP 系统中。我们提供了完整的 API 文档和 Node.js/Python SDK。

### Q8：ReAct Agent 是什么？和普通 AI 有什么区别？
ReAct Agent 是 QiCloud 最新的 AI 执行模式。普通 AI 只能"你说什么它答什么"，而 ReAct Agent 可以自主使用工具——比如查询知识库、读取客户历史记录、分析客户阶段、生成并发送跟进消息——整个过程自主完成，无需人工逐步操作。一个 ReAct Agent 可以替代一个初级 SDR 的日常工作。

### Q9：数据安全性如何保障？
数据传输全程 HTTPS + TLS 1.3 加密；数据库存储使用 AES-256 加密；用户认证采用 JWT + bcrypt 12 轮哈希；所有 API 请求经过限流保护（100 次/分钟）。企业版通过了国家信息安全等级保护二级认证，并支持完全私有化部署，数据不出客户机房。

### Q10：网页 Widget 怎么接入？
只需在网站 HTML 的 `<head>` 标签中加入一行 JS 代码即可。接入后，网站右下角会出现聊天图标，访客点击即可与 AI 对话。Widget 的配色和文案可以在后台自定义。整个接入过程不超过 5 分钟。

## 二、价格与合同（8 题）

### Q11：三个套餐的主要区别是什么？
基础版 ¥1,999/月 → 3 个坐席、10,000 条消息/月，适合 5-20 人团队试水；
专业版 ¥5,999/月 → 10 个坐席、50,000 条消息/月、全渠道、活动引擎，适合 20-100 人正式团队；
企业版 ¥19,999/月 → 不限坐席、不限消息、私有部署、定制训练，适合 100 人以上企业。

### Q12：年付有优惠吗？
有。年付享受 8 折优惠。以专业版为例，月付 ¥5,999×12 = ¥71,988，年付 ¥57,590，节省 ¥14,398。

### Q13：超出消息量怎么收费？
基础版超出后 ¥0.3/条，专业版 ¥0.2/条，企业版不限量。建议在后台设置月度预算提醒，避免意外超支。也可以提前购买消息包来降低成本。

### Q14：可以随时升级或降级套餐吗？
可以随时升级，差价按天折算。降级在当月结束后生效。例如基础版用了 10 天升级到专业版，只需支付剩余 20 天的差价。

### Q15：有免费试用吗？
有。所有套餐提供 14 天免费试用（基础版功能范围），无需绑定信用卡。试用期间可以随时升级。试用到期后如果不付费，数据保留 30 天，之后自动清除。

### Q16：私有化部署要多少钱？
企业版包含私有化部署能力，但需要一次性支付 ¥49,000 的部署服务费。包括环境安装、配置调优、运维培训，通常在 2-3 周内完成。如果客户有自己的运维团队，可以自行部署，免除部署费。

### Q17：你们的退款政策是什么？
月付客户可随时取消，当月费用不退，下月不再续费。年付客户在购买后 30 天内可全额退款，超过 30 天按已使用月份（按月付原价计算）扣除后退还余额。

### Q18：可以开增值税专用发票吗？
可以。所有套餐费用均可开具增值税专用发票（6% 服务费税率），发票在付款后 3 个工作日内寄出。

## 三、技术接入（7 题）

### Q19：API 文档在哪里？
API 文档地址：https://docs.qicloud.cn/api。目前提供 RESTful API，支持 JSON 格式请求和响应。认证方式支持 API Key（Bearer Token）和 Cookie Session 两种。SDK 方面提供了 Node.js 和 Python 版本。

### Q20：怎么接入企业微信？
在后台"渠道管理"→"企业微信"中，扫码授权即可完成接入。授权后，企业微信的消息会实时同步到 QiCloud 统一收件箱，AI 可以自动回复。接入过程大约需要 2 分钟。注意需要使用企业微信管理员账号授权。

### Q21：知识库上传文档后多久可以检索？
通常 30 秒内完成处理和索引。较大的 PDF 文件（接近 10MB）可能需要 1-2 分钟。处理完成后文档状态会从"处理中"变为"已就绪"，此时即可在对话中检索到。你可以在"知识库"页面查看文档处理进度。

### Q22：支持自定义 AI 模型训练吗？
企业版支持。你可以用历史客服对话数据对 DeepSeek 模型进行微调，让 AI 更贴合你的行业术语和话术风格。微调需要提供至少 500 组对话样本，训练周期约 5-7 个工作日。费用 ¥29,000 起。

### Q23：是否支持 SSO 单点登录？
企业版支持 SAML 2.0 和 OIDC 协议的 SSO 集成。支持的企业身份提供商包括：飞书、钉钉、企业微信、Microsoft Entra ID、Okta。接入配置通常 1-2 个工作日完成。

### Q24：系统 SLA 是多少？
基础版和专业版无 SLA 承诺（尽力保障）。企业版提供 99.9% 月度可用性 SLA，若未达标按当月费用的 10% 赔偿。我们使用的云基础设施（Supabase + Vercel + Railway）在过去 12 个月的实际可用性为 99.95%。

### Q25：数据可以导出吗？是什么格式？
专业版和企业版支持数据导出。可导出的数据包括：线索列表（CSV/Excel）、对话记录（JSON）、活动数据（CSV）、AI 调用指标（CSV）。导出操作在后台"设置"→"数据管理"中执行，大量数据导出可能需要几分钟。

## 四、售后与支持（5 题）

### Q26：遇到问题怎么联系你们？
- 在线客服：工作日 9:00-18:00（基础版/专业版），7×24 小时（企业版）
- 电话支持：400-888-QiCloud（专业版及以上），工作日 9:00-21:00
- 工单系统：后台"帮助"→"提交工单"，响应时间 2 小时内
- 企业版配备专属客户成功经理，可直接微信联系

### Q27：有没有使用培训？
有。所有新客户都有一对一线上产品演示和操作培训（约 1 小时），不额外收费。专业版和企业版额外提供每月一次的线上答疑会，以及按需的进阶培训。也可以访问我们的帮助中心（help.qicloud.cn）查看操作指南和视频教程。

### Q28：你们的服务器在哪里？数据储存在哪里？
默认部署在阿里云上海和北京节点。企业版私有化部署由客户自主选择服务器位置。数据不会跨境传输。我们目前正在评估 AWS 东京节点以满足部分客户对海外数据存储的需求。

### Q29：如果我停止使用，数据会保留多久？
主动取消后，数据保留 30 天供你导出。30 天后系统自动清除所有数据且不可恢复。如果你在 30 天内重新激活账号，所有数据保持不变。企业版私有化部署不受此限制——数据完全在你自己的服务器上。

### Q30：有没有用户社区或同行交流？
有。我们运营一个 Slack 社区和微信群，所有付费客户均可加入。社区里有产品更新公告、使用技巧分享、行业最佳实践讨论。企业版客户还有季度闭门交流会，与同规模企业的 AI 自动化负责人深度交流。
