# 启云科技 QiCloud — 产品功能介绍

> 版本：V3.2 | 更新日期：2026-06-15
> QiCloud 是一站式企业级 AI 客服与销售自动化 SaaS 平台，帮助 50-500 人的 B2B 企业实现客户沟通的智能化、自动化和可量化。

---

## 一、AI 销售坐席

QiCloud 的核心能力是 **AI 销售坐席（AI Sales Agent）**，一个能自主完成客户跟进、线索筛选、话术推荐和会议预约的智能助手。

### 1.1 智能线索管理

- **自动评分**：基于 BANT（预算、权限、需求、时间）四维度对每条线索打分 0-100 分，自动标记"高意向/中等/低意向"
- **阶段流转**：新线索 → 已联系 → 已确认 → 方案中 → 洽谈中 → 已成交/已流失，全流程可视化
- **重复线索去重**：基于邮箱和公司名自动合并重复记录，避免多销售同时跟进同一客户

### 1.2 AI 消息组合

- **理解客户意图**：AI 阅读客户消息后，结合知识库和销售话术自动生成个性化回复草稿
- **多人审核**：所有 AI 草稿默认进入"待审核"状态，销售经理确认后才可发送，杜绝 AI 幻觉风险
- **12 种邮件模板**：欢迎邮件、冷启动、跟进、提案、异议处理等，覆盖完整销售周期
- **7×24 小时值守**：客户在官网、微信、邮件任何渠道发消息，AI 在 30 秒内响应

### 1.3 多渠道统一收件箱

| 渠道 | 支持情况 | 说明 |
|------|---------|------|
| 企业微信 | ✅ 完整支持 | 消息实时同步，支持群聊 |
| 个人微信 | ✅ 完整支持 | 通过合规 API 接入 |
| 邮件 | ✅ 完整支持 | 使用客户自有邮箱域名 |
| 网页 Widget | ✅ 完整支持 | 一行 JS 代码嵌入官网 |
| API 接入 | ✅ 完整支持 | RESTful API，支持自定义渠道 |

所有渠道的消息汇聚到同一个收件箱，按客户自动分组为对话线程。

### 1.4 外呼活动引擎

- **多步骤序列**：支持 email/ai_email/react/delay/condition 五种步骤类型，灵活编排
- **ReAct Agent 模式**：最新支持 ReAct 推理执行，Agent 可自主查询知识库、分析历史记录、决定最佳跟进策略
- **A/B 测试**：同一活动可设置多套话术，系统自动统计各版本的打开率和回复率
- **自动暂停规则**：客户回复后自动停止后续步骤，转为人工跟进

## 二、RAG 知识库

QiCloud 的知识库采用 **混合检索（Hybrid Search）** 技术：

```
用户上传文档（PDF/DOCX/TXT/MD/FAQ）
  → 智能分段（递归段落+句子边界，1000字符/块，200字符重叠）
  → 向量嵌入（OpenAI text-embedding-3-small，1536维）
  → 存储到 PostgreSQL + pgvector + tsvector
  → 检索时并行执行：向量语义搜索 + 全文关键词搜索
  → RRF 融合排序（k=60）→ 返回最相关的 5 个文本块
```

### 2.1 文档管理
- 支持格式：PDF、Word（DOCX）、Markdown、纯文本、FAQ 问答对
- 上传即自动处理，单个文件最大 10MB
- 按部门和权限隔离，销售部、客服部各自独立知识库

### 2.2 问答效果
- 有答案时：AI 引用来源回答，标注文档名和段落编号
- 无答案时：明确告知"知识库中未找到相关信息"，绝不编造
- 支持追问和多轮对话上下文理解

## 三、数据分析看板

### 3.1 销售漏斗
- 实时漏斗图展示各阶段线索数量
- 成交金额统计（支持手动录入商机金额）
- 转化率：线索→已联系→已确认→方案→洽谈→成交的每一跳转化率

### 3.2 AI 效能
- P50/P95 延迟：AI 响应速度毫秒级监控
- Token 消耗趋势：每日/每周 prompt 和 completion token 用量
- AI 回复率：自动生成 vs 人工发送的占比
- 人工介入率（HITL Rate）：需要销售审核的 AI 草稿比例

### 3.3 活动效果
- 邮件打开率、回复率、退订率
- 每场活动的 ROI 估算

## 四、多租户与权限

### 4.1 组织架构
- 每个客户独立租户，数据物理隔离（独立 PostgreSQL Schema）
- 一个企业可有多个工作空间（如"华东销售部""华南销售部"）

### 4.2 角色权限矩阵

| 权限 | 管理员 | 销售经理 | 销售代表 | 只读用户 |
|------|:---:|:---:|:---:|:---:|
| 管理组织 | ✅ | — | — | — |
| 管理成员 | ✅ | ✅ | — | — |
| 管理 AI 助理 | ✅ | ✅ | ✅ | — |
| 管理线索 | ✅ | ✅ | ✅ | — |
| 删除线索 | ✅ | ✅ | — | — |
| 管理活动 | ✅ | ✅ | ✅ | — |
| 查看数据 | ✅ | ✅ | ✅ | ✅ |

### 4.3 安全合规
- 数据传输全程 HTTPS + TLS 1.3
- 数据存储 AES-256 加密
- JWT + bcrypt 12 轮哈希 + httpOnly Cookie 认证
- 通过国家信息安全等级保护二级认证
- 支持私有化部署（企业版）
